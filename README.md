# ArgentoPro ARK x5

Página del server argentino de ARK: Survival Evolved (todo x5, cluster y mapa rotativo por votación).

- `index.html`: la página.
- `dinos.js`: guía de tameo de las criaturas (editable).
- `api/public.js`: función de Vercel que trae el estado en vivo de los mapas. Necesita la variable `ARK_HOST` con la IP del server.
